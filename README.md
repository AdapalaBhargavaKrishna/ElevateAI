## What is ElevateAI?

ElevateAI is a full-stack AI career platform that helps candidates go from **"I think I'm ready"** to **"I got the offer."**

It combines resume intelligence, real-time AI interview simulation, personalized learning roadmaps, and DSA coding practice into one unified experience — powered by a multi-agent AI pipeline running on **Groq (Llama 3.3 70B)** and **Google Gemini**.

---

## Features

### 📄 Resume Analyzer
Upload your resume (PDF or DOCX) and get a deep multi-dimensional analysis in seconds.

- **4-Agent Pipeline** — Parser → Skills Extractor → Scoring Agent → ATS Agent run sequentially, each with its own responsibility
- **Resume Score** — Graded across Contact Info, Skills, Experience quality, Projects, Education, and Certifications
- **ATS Compatibility Check** — Detects formatting red flags (special characters, non-ASCII, pipe tables), keyword gaps by domain, and section completeness
- **Skills Analysis** — Identifies programming languages, tools, frameworks, and soft skills separately
- **Grade + Feedback** — Letter grade (A–F), actionable weaknesses, and improvement suggestions

### 🎤 AI Interview Simulator
A full end-to-end mock interview experience with real-time AI evaluation.

- **5 Interview Types** — Technical, HR, Behavioral, System Design, and DSA (coding)
- **4 Experience Levels** — Fresher, Junior, Mid, Senior
- **Dual Modes:**
  - **Interview Mode** — Strict evaluator, no hints, no guidance. Pure simulation
  - **Learning Mode** — Supportive coach that teaches concepts after each answer
- **5-Axis Evaluation** — Each answer scored on Technical Accuracy, Depth, Clarity, Real-World Relevance, and Structure (0–10 each)
- **AI Follow-up Questions** — If your answer is weak, the AI probes with a targeted follow-up to give you a chance to recover
- **Progressive Hints** — Two-level hint system (subtle clue → deeper guidance) available on request
- **Per-Question Breakdown** — Strengths, weaknesses, improvement suggestions, and teaching notes after every answer
- **Session Summary** — Overall verdict, top strengths, areas to improve, and a final score at the end
- **Interview History** — All past sessions stored and reviewable anytime

### 💻 DSA Playground
A full coding environment for algorithm practice with AI evaluation.

- **Monaco Editor** (the same editor powering VS Code) with JavaScript and Python support
- **AI-Generated Problems** — Topic-based (Arrays, Trees, Graphs, DP, etc.) at Easy / Medium / Hard
- **Live Code Execution** — Run code against test cases directly in the browser
- **AI Code Review** — Time complexity, space complexity, code quality score, and optimization hints
- **Hints System** — Two progressive hints per problem before revealing the approach

### 🗺️ Learning Roadmap
Personalized career roadmaps generated by AI based on your target role and current skills.

- Generates **3–6 phase roadmaps** with timelines, goals, and resources per phase
- **Phase-locked progression** — unlock the next phase only after passing the current assessment
- **Built-in MCQ Assessments** — 10 questions per phase, auto-generated and specific to that phase's skills
- **Resource Recommendations** — Curated courses, books, documentation, and practice projects per phase
- **Skill Gap Analysis** — Identifies exactly what's missing between your current skills and the target role
- **Industry Insights** — Demand level, salary range, top hiring companies, and key technologies

### 📊 Dashboard & Analytics
Everything in one place.

- **ElevateScore** — A composite score (0–1000) calculated across Interview performance (35%), ATS score (20%), Resume score (10%), Roadmap progress (15%), Assessment pass rate (10%), and Profile completeness (10%)
- **Analytics Page** — Interview score trends over time, category performance breakdown, interview type distribution (pie chart)
- **Dashboard** — Quick stats on interviews completed, latest resume score, roadmap progress, and recent activity

### 🤖 AI Assistant
A context-aware chat assistant built into the platform. Ask anything about your career, resume, or interview prep — it knows the platform context.

### 👤 Profile & My Info
Full professional profile management — skills, experience, education, projects, certifications, social links (GitHub, LinkedIn, LeetCode). Profiles generate a shareable preview page.

## Architecture

ElevateAI is built as three independent services that communicate via internal API keys.

```
┌─────────────────────────────────────────────────────────┐
│                      User Browser                       │
│              Next.js 16 Frontend (Port 3000)            │
└────────────────────────┬────────────────────────────────┘
                         │ REST API calls
                         ▼
┌─────────────────────────────────────────────────────────┐
│             Express API Service (Port 4000)             │
│   Auth · User Info · Interviews · Resume · Roadmap      │
│          Prisma ORM  ──►  PostgreSQL Database           │
└────────────────────────┬────────────────────────────────┘
                         │ Internal API Key (X-Internal-Key)
                         ▼
┌─────────────────────────────────────────────────────────┐
│           FastAPI AI Service (Port 8000)                │
│                                                         │
│   ResumeOrchestrator                                    │
│   ├── ParserAgent      (PDF/DOCX → structured JSON)     │
│   ├── SkillsAgent      (skill extraction & tagging)     │
│   ├── ScoringAgent     (multi-dimensional scoring)      │
│   └── ATSAgent         (ATS compatibility analysis)     │
│                                                         │
│   Groq (Llama 3.3 70B)  ◄──►  Google Gemini            │
└─────────────────────────────────────────────────────────┘
```

The AI service is completely isolated — it has no database access and receives data only via authenticated internal requests from the API service. This means the AI layer can be swapped, scaled, or replaced independently.

## Getting Started

### Prerequisites

- Node.js 20+
- Python 3.11+
- PostgreSQL database ([Supabase](https://supabase.com) for free cloud)
- [Groq API key](https://console.groq.com) (free tier available)
- [Google Gemini API key](https://aistudio.google.com) (free tier available)
- Google OAuth credentials (optional, for Google sign-in)

---

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/ElevateAI.git
cd ElevateAI
```

---

### 2. Set up the AI Service (FastAPI)

```bash
cd ai-services

# Create and activate virtual environment
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

Create `.env` in `ai-services/`:

```env
GEMINI_API_KEY=your_gemini_api_key_here
GROQ_API_KEY=your_groq_api_key_here
LLM_MODEL=gemini-2.0-flash
INTERNAL_API_KEY=your_secret_internal_key_here
```

Start the AI service:

```bash
uvicorn app.main:app --port 8000 --reload
```

---

### 3. Set up the API Service (Express)

```bash
cd ../api-services
npm install
```

Create `.env` in `api-services/`:

```env
DATABASE_URL=postgresql://username:password@localhost:5432/elevateai
JWT_ACCESS_SECRET=your_access_secret_here
JWT_REFRESH_SECRET=your_refresh_secret_here
INTERNAL_API_KEY=your_secret_internal_key_here   # Must match AI service
AI_SERVICE_URL=http://localhost:8000
GOOGLE_CLIENT_ID=your_google_client_id           # Optional
GOOGLE_CLIENT_SECRET=your_google_client_secret   # Optional
GOOGLE_CALLBACK_URL=http://localhost:4000/auth/google/callback
NODE_ENV=development
```

Set up the database:

```bash
npx prisma migrate dev
npx prisma generate
```

Start the API service:

```bash
npm run dev
```

---

### 4. Set up the Frontend (Next.js)

```bash
cd ../frontend
npm install
```

Create `.env.local` in `frontend/`:

```env
NEXT_PUBLIC_API_URL=http://localhost:4000
```

Start the frontend:

```bash
npm run dev
```

---

### 5. Open the app

Visit [http://localhost:3000](http://localhost:3000) — sign up and you're in.

## Key Design Decisions

**Why three separate services?**
The AI service is the most resource-intensive and failure-prone component. Isolating it means the main API and database stay up even if an LLM provider has an outage. It also allows independent scaling — the AI tier can be deployed on a GPU-optimised instance while the API runs on a basic server.

**Why Groq + Gemini?**
Groq provides extremely fast inference for Llama 3.3 70B, making interview evaluation feel real-time. Gemini is used as a fallback for longer-context tasks like roadmap generation. Having two providers means the platform keeps working even when one is down.

**Why the multi-agent resume pipeline?**
A single LLM call for "analyse this resume" produces inconsistent, hard-to-debug results. The 4-agent pipeline (Parse → Extract Skills → Score → ATS) gives each agent a single clear responsibility, makes failures easier to trace, and produces structured, predictable output at every stage.

**ElevateScore formula:**
```
ElevateScore = (Interview Avg × 0.35) + (ATS Score × 0.20) +
               (Resume Score × 0.10) + (Roadmap Progress × 0.15) +
               (Assessment Pass Rate × 0.10) + (Profile Completeness × 0.10)

Final score scaled to 0–1000
```

## Environment Variables Reference

### AI Service (`ai-services/.env`)

| Variable | Description |
|---|---|
| `GROQ_API_KEY` | Groq API key for Llama 3.3 70B inference |
| `GEMINI_API_KEY` | Google Gemini API key |
| `LLM_MODEL` | Gemini model name (e.g. `gemini-2.0-flash`) |
| `INTERNAL_API_KEY` | Shared secret for AI ↔ API service communication |

### API Service (`api-services/.env`)

| Variable | Description |
|---|---|
| `DATABASE_URL` | PostgreSQL connection string |
| `JWT_ACCESS_SECRET` | Secret for signing access tokens (15 min expiry) |
| `JWT_REFRESH_SECRET` | Secret for signing refresh tokens (7 day expiry) |
| `INTERNAL_API_KEY` | Must match the AI service value |
| `AI_SERVICE_URL` | Base URL of the FastAPI AI service |
| `GOOGLE_CLIENT_ID` | Google OAuth client ID (optional) |
| `GOOGLE_CLIENT_SECRET` | Google OAuth client secret (optional) |
